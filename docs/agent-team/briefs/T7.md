# T7 brief: merge into SQLite, reports, clean-and-merge, review-report

Goal: merge every staged source into the main SQLite database exactly as D3/D8/D14/D15 say, write the
masked run report (requirements §6.4), and provide the two CLIs behind the `clean-and-merge` and
`review-report` skills. This is the core data-integrity step: re-runs must be stable and nothing is
deleted from `contacts` or `suppressions`.

Read `docs/agent-team/briefs/_common.md` first.

Lease: `scripts/lib/merge.ts`, `scripts/lib/priority.ts`, `scripts/lib/report.ts`,
`scripts/clean-and-merge.ts`, `scripts/review-report.ts`, and their `*.test.ts`.

Already in the repository (read, do not edit): `scripts/lib/{paths,config,env,overrides,db,cli,errors}.ts`
(T5), `scripts/lib/{meta,stage}.ts` + `scripts/lib/read/**` (T6), `scripts/lib/email/**` (T2),
`scripts/lib/mask.ts` (T3), `fixtures/**` incl. `fixtures/expected.json` (T4). Read their exports before
writing code; if one of them does not do what this brief assumes, stop and report.

Behavior of `mergeStaged(results: SourceStageResult[], { db, config, metas, overrides, runId, now })`
(one SQLite transaction; caller makes the backup first with `backupDb`):
1. `sources`: upsert each processed source from its meta. `priority`: D8 (config.sources.priority first,
   then unlisted by exported_at desc, then name; nulls last) over all sources in the db + processed.
   `counts_as_opt_in` = basis in `config.consent.opt_in_bases` or name in `config.consent.opt_in_sources`.
2. Read `rows.parquet` of each processed source with DuckDB. Representative row per (email, source):
   the newest file (date `YYYY-MM-DD` in the file name; files without a date rank by their order in
   meta.files, later = newer, below dated files), then the lowest row_number.
3. `contacts` (upsert by email; keep id): name / locale = first non-empty value by source priority, using
   each source's representative row; `flags` = sorted union over all rows; `email_status` from flags
   (typo_suspect > role > valid); `suggested_email` from a typo row; `first_seen_at` = min created_at over
   all rows (any source, including sources not processed in this run: recompute from contact_sources);
   `orphaned_at` = NULL when present again; `updated_at` = now only when something changed.
4. `contact_sources`: for processed sources, delete their rows and insert fresh ones: raw_email and
   raw_fields from the representative row, first_seen_at = min created_at, last_seen_at =
   max(coalesce(last_seen_at, created_at)), occurrences, files (sorted JSON array).
5. `consents`: for processed sources, replace rows; one row per (contact, source): rows with a non-unknown
   consent_status decide; newest file wins; within one file `denied` wins; evidence JSON
   `{"column","value","file","row_number"}`; recorded_at = that row's last_seen_at ?? created_at ??
   meta.exported_at; no decisive row → `unknown`, evidence NULL. Then apply `overrides.consents`
   (status from the override, evidence `{"override": note}`); an override for a contact/source that does
   not exist → warning in the report.
6. Orphans: contacts with no contact_sources row and orphaned_at NULL → orphaned_at = now (count them).
   Never delete contacts. Sources present in the db but no longer in resources → warning only.
7. `rejected_rows`: replace rows of processed sources with this run's (run_id). `imports`: insert one row per
   file (sha256, encoding, rows_read). `suppressions`: insert overrides.suppressions with source
   'override' (INSERT OR IGNORE on the UNIQUE key). Never delete suppressions.
8. Return `MergeStats` (overlap from `v_source_overlap`, a ≠ b pairs once with a < b).

`report.ts`: `buildReport(stage, merge, …)` and `writeReport(report, reportsDir)` → `<run_id>.json`, `<run_id>.md`,
and copies `latest.json` / `latest.md`. Markdown: per-file table (rows_read, empty, invalid, cells_split,
dup_in_file, role, typo_suspect, encoding + how, mappings with confidence), cross-source dups, unique
contacts, overlap matrix, priority order used, overrides applied, warnings, and the samples of
`RunReport` — **masked only** (`maskEmail`), at most 20 per list.

`clean-and-merge [--source <name>]... [--dry-run] [--workspace p] [--json]`: requireWorkspace; load config,
env, overrides; every directory in resources/ without meta.md → listed as "run add-source", skipped;
load all metas first (any error → exit 1 before staging); stage each source; `--dry-run` stops after
writing the report (no backup, no db write); otherwise backup → `runs` row → merge → report → runs status.
On error the transaction rolls back and the run is marked failed. Prints a short masked summary + report path.

`review-report [--workspace p] [--json]`: reads `output/reports/latest.json` and the db; prints (masked)
the decisions a human must make: typo suspects without a decision in typo-decisions.yaml, encodings
detected with `auto`, mappings below 0.8, sources without meta.md, consent_basis `unknown` sources,
newly orphaned contacts, override warnings. It writes `output/reports/pending-decisions.yaml` with the
full values and ready-to-edit entries (`action: accept|reject` left blank) for the human to review and
move to `workspace/overrides/`; stdout never shows a full address.

Tests (temp workspace from `fixtures/` under `os.tmpdir()`, using `migrate` and `stageSource`):
- totals match `fixtures/expected.json` (contacts_total, cross_source_dups, overlap) after overrides;
- re-run with the same inputs → identical `contacts` (ids included), `contact_sources`, `consents`;
- consent rules: change between the two shop-alpha exports (newest wins), denied wins within one file,
  override applied;
- remove one file and re-run → its exclusive addresses get orphaned_at and leave both sendable views;
  restoring it clears orphaned_at with the same id;
- manual suppression override → address absent from `v_not_blocked` and `v_sendable_strict`;
- report and review-report stdout contain no unmasked address (regex check).

scripts/clean-and-merge.test.ts scripts/review-report.test.ts`; then on a temp workspace built with
`node scripts/init-workspace.ts --workspace <tmp>` + copied fixtures: `node scripts/clean-and-merge.ts
--workspace <tmp>` twice and `node scripts/review-report.ts --workspace <tmp>` (paste outputs).
