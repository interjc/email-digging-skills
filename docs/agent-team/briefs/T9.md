`CONTRIBUTING.md`, `apps/README.md`.

`.claude/skills` and `.agents/skills` are symlinks to `skills/` (D18).

Skills (one directory each, `SKILL.md` with YAML frontmatter `name` and `description`; the description
says what it does and when to use it, in one or two sentences, third person):
`init-workspace`, `add-source`, `clean-and-merge`, `review-report`, `query-list`, `mask-data`,
`export-to-provider`. Each body: purpose; preconditions (workspace initialized and git-ignored, else stop
and run init-workspace; AGENTS.md data rules); exact commands with flags; how to read the output; what
needs a human decision and where it is recorded (overrides files, meta.md, config.yaml); what the agent
must never do (read raw files into context, print full addresses, edit resources/, write to providers
without confirmation, delete db content). Use only agent-neutral wording and plain shell commands; no
vendor-specific tools. `add-source` must say: read a `NOTES.txt` in the source directory if present,
never overwrite an existing `meta.md`, confirm suspected duplicates and auto encodings with the human.
`clean-and-merge` must say: first real-data run only after the human confirms the files and meta.md are
ready; run `--dry-run` first. `export-to-provider`: strict list by default, `--apply` is not available in
phase 1. Keep each SKILL.md under ~120 lines.

README.md (English): what it is and why (self-hosted, own database, providers are downstream); status
(phase 1 scope); requirements (Node >= 22.18, pnpm; DuckDB bundled via @duckdb/node-api 2.0.1; network
once for DuckDB extensions); quick start (`pnpm install`, `pnpm init-workspace --demo`, what it prints);
pipeline steps mapped to skills; directory layout (requirements §3, adjusted to what exists); data safety
(workspace git-ignored, masking, pre-commit scan + gitleaks, only output/masked leaves the machine);
using with agents (Claude Code and Codex discover `skills/` through the symlinks; other agents read
AGENTS.md and skills/); consent note (strict list default; not legal advice); license MIT. README.zh-CN.md:
faithful Simplified Chinese translation, linked from the top of README.md and back.

CONTRIBUTING.md: setup, hooks (`init-workspace` sets core.hooksPath; gitleaks optional locally, always in
CI), tests only with fixtures (`node scripts/make-fixtures.ts` regenerates them), migration rule, adding a
provider (providers/README.md), no real data or user-specific config, PR checklist (typecheck, tests, scan).

`apps/README.md`: placeholder per requirements §8 (later; local only on 127.0.0.1; reuses scripts/lib;
writes decisions to overrides; masked by default).
