# T3 brief: masking module, staged-email scan, git hook, CI

Goal: (a) masking functions so no agent or log ever sees a full address or name (rule R2);
(b) a scan that refuses commits containing real email addresses (rule R7); (c) the pre-commit hook
and a GitHub Actions CI workflow. The repository is public: (b) and (c) are the last line of defense.

Read `docs/agent-team/briefs/_common.md` first.

Lease:
- `scripts/lib/mask.ts` + `scripts/lib/mask.test.ts`
- `scripts/check-staged-emails.ts` + `scripts/lib/scan/**` (helpers incl. a minimal in-memory zip
  reader for .xlsx using `node:zlib` `inflateRawSync`) + `scripts/lib/scan/*.test.ts`
- `.githooks/pre-commit` (POSIX sh, executable)
- `.github/workflows/ci.yml`, `.gitleaks.toml`

(a) Masking: exactly R2. Exports: `maskEmail`, `maskName`, `maskPhone`, `maskValue`, `hmacLocalPart`
(use `node:crypto` createHmac). Grapheme-aware first character (`Intl.Segmenter`), so `𠀀田` → `𠀀*`.

(b) `node scripts/check-staged-emails.ts [--all] [--json]`:
- default: files in `git diff --cached --name-only --diff-filter=ACMR`, content read from the index
  (`git show :<path>`, as a Buffer), so unstaged edits do not matter; `--all`: `git ls-files`.
- detection and allow rules exactly R7. Report `path:line: <masked address>` (use maskEmail; never print
  the full address). Exit 0 clean, 1 findings, 2 git error.
- Tests: build temp git repos under `os.tmpdir()` (git init, git add) and assert exit codes and
  output for: allowed example domains, a disallowed address (construct it at runtime so this test file
  itself contains no literal real address), `email-scan:allow` lines, a cp932-encoded file, a UTF-16LE
  file, and an xlsx. For the xlsx test, create it with DuckDB:
  `INSTALL excel; LOAD excel; COPY (SELECT 'x' AS email) TO '<path>.xlsx' (FORMAT xlsx);`
  via `@duckdb/node-api` (`DuckDBInstance.create(':memory:')`, `connect()`, `run(sql)`), verified to work.

(c) `.githooks/pre-commit`: run `node scripts/check-staged-emails.ts`; then, if `gitleaks` is on PATH,
`gitleaks git --staged --redact --no-banner` (fail on findings); if not, print one line saying it was
skipped. `init-workspace` (another task) sets `core.hooksPath=.githooks`; do not set it yourself.
`.github/workflows/ci.yml`: on push and pull_request; ubuntu-latest; actions/checkout@v4 with
fetch-depth 0; pnpm/action-setup@v4; actions/setup-node@v4 with node 24 and pnpm cache;
`pnpm install --frozen-lockfile`; `pnpm typecheck`; `node scripts/check-staged-emails.ts --all`;
`pnpm test`; gitleaks/gitleaks-action@v2 (env GITHUB_TOKEN). `.gitleaks.toml`: extend the default
config, allowlist `fixtures/` only for generic-api-key false positives if needed, nothing else.

Acceptance: tsc (as in common), `node --test scripts/lib/mask.test.ts "scripts/lib/scan/*.test.ts"`,
`sh -n .githooks/pre-commit`, and `node scripts/check-staged-emails.ts --all` on this repository
(expected: exit 0). Paste outputs.
