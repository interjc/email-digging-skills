## Scope

Everything in requirements step 1 (aggregate, tag, clean, dedupe, merge into a queryable database),
plus the provider interface with a Listmonk **dry-run CSV export** only (no API calls yet).
Skills: init-workspace, add-source, clean-and-merge, review-report, query-list, mask-data,
export-to-provider (dry-run).

## Module interfaces (exports other tasks rely on)

- `lib/email/normalize.ts`: `normalizeEmailCell(cell): EmailCandidate[]`
- `lib/mask.ts`: `maskEmail`, `maskName`, `maskPhone`, `maskValue`, `hmacLocalPart`
- `lib/paths.ts`: `repoRoot()`, `resolveWorkspace(opts?)`, `workspaceLayout(ws)` → `{ resources, overrides, output, staging, reports, masked, exports, database, backups, dbPath }`, `requireWorkspace(opts?)` (throws `PreconditionError`, CLIs exit 2)
- `lib/config.ts`: `loadConfig(opts?): PipelineConfig` (defaults when config.yaml is missing)
- `lib/env.ts`: `loadEnv(repoRoot): Record<string,string>` (parses `.env`, never logs values)
- `lib/overrides.ts`: `loadOverrides(dir): Overrides` (missing files = empty lists)
- `lib/db.ts`: `openDb(path, {readonly?})`, `migrate(db, migrationsDir)` returns applied versions, `backupDb(dbPath, backupsDir, keep)` returns backup path or null when no db yet
- `lib/meta.ts`: `loadMeta(sourceDir): SourceMeta` (validates; source must equal dir name), `renderMetaDraft(probe…): string`
- `lib/read/*`: `probeFile(path, metaFile?): Promise<FileProbe>`, `readRows(path, metaFile, probe): AsyncIterable<{ row_number, cells: Record<string,string|null> }>`
- `lib/stage.ts`: `stageSource(meta, layout, overrides): Promise<SourceStageResult>`
- `lib/merge.ts`: `mergeStaged(results, {config, layout, overrides, runId}): MergeStats`
- `lib/report.ts`: `buildReport(...)`, `writeReport(report, reportsDir)` → `{ md, json }` paths (masked)

## Paths through the change

- Workspace missing / inside repo but not ignored → every CLI except init exits 2 with the fix.
- meta.md invalid → clean-and-merge stops before touching the database (exit 1), reports which field.
- Unknown encoding (`auto`) → decoded with the first candidate that succeeds; report lists it under "confirm".
- Low-confidence column mapping (< 0.8) → used, listed for review; email column not found → that file is skipped with an error in the report, run status `failed`, database untouched.
- Merge failure → transaction rolled back; the backup from this run remains.
- Re-run with unchanged inputs → identical contacts/consents/contact_sources; `imports` and `runs` gain rows.
- Address removed from all sources → `orphaned_at` set, excluded from both sendable views, reported.
- Suppression from override → inserted once (UNIQUE), never removed by the pipeline.
